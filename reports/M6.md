# M6 — Real inference and role-isolated training integration

Implemented actual OpenAI-compatible HTTP inference, a shared atomic TokenLedger,
and local Hugging Face generation with separate role instances and checkpoint
loading. HTTP requires an explicit upper bound for the provider's serialized
prompt tokens; missing usage is an error. Ambiguous failures consume reservations.
Raw requests/responses (without authorization headers) enter the journal.
Generated typed representations, experiment programs and executable meta code
enter the same independent controller gates. World programs use the independent
world certifier; no model-provided answers become evaluation labels.

LoRABackend performs actual reward-weighted SFT or clipped importance policy
gradient using torch, transformers and PEFT. It loads a fresh shared base per role,
trains only LoRA parameters, rejects zero/nonfinite updates, and saves checksummed
adapter manifests. RL requires the actual behavior policy identity, exact sampled
tokens and their log likelihood (unfiltered temperature-one sampling). Training
rewards come from independently executed TRAIN interactions; private development
and final test outcomes never enter prompts or training. Updated weights generate
new executable candidates before private evaluation, and acceptance still requires
the original Gate. Local assets only; no automatic model downloads.

Actually executed: 68 tests passed in 30.740 seconds before the exact-token RL
record refinement; six targeted model/training tests pass. HTTP server fixtures
exercise the real transport, metering, truncation, and secret-free journaling.
A labeled protocol fixture exercises generated code through Controller and Replay.
These fixtures are NOT model training or model performance results.

Unverified: real provider inference, actual GPU/CPU neural model training,
checkpoint loading with PEFT and measured model improvements. This environment has
no model credentials, local model assets, torch, transformers or PEFT. Missing
capabilities raise CAPABILITY_UNSUPPORTED and do not produce training receipts.
RL uses an offline clipped importance objective, not PPO. A provider-specific
prompt bound is required for remote inference; generic remote LoRA upload is not
supported. Training uses an explicit step cap, not a hard wall-clock/GPU-time cap.
M7 must complete controls, reproducible CLI instructions and final review.
