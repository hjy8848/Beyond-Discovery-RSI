# M2 — Independent boundary certificates

`core/boundary.py` declares versioned finite hypothesis families and independently
audits observations before generating certificates. Exhaustive refutation,
consistent-family search failure, consistent selection and resource uncertainty
are distinct outcomes. Certificates bind family, scope, evidence and every
refutation witness; verification recomputes them. Claims apply only to the
declared family, never to arbitrary LLM representations.

The retained finite runtime now attaches these certificates and accounts for
proof predictions and reference audit costs. Diagnosis requires certified family
refutation across independent source clusters; a prediction mismatch alone is
insufficient. Gate and trusted scoring definitions are unchanged.

Actually executed: all 45 tests passed, including the original 41 regressions and
four proof/tampering/search-budget tests. No external model or formal solver was
used. Infinite-family impossibility proofs remain unsupported: resource-limited
search reports UNDETERMINED instead of claiming exhaustion.
