# C3: independent counterexamples and coding meta evolution

Single-version public wrong answers receive independently reproduced
SOLUTION_REFUTED certificates. The finite-family SPACE_REFUTED verifier and
representation diagnosis remain unchanged. Challenger metrics recognize only
independently certified, reproduced failures; statistical Gate thresholds and
implementation are unchanged.

Restricted world proposals contain a train parent, exact frozen Scientist
artifact hash and new input only. Certification requires an operator-reviewed
input validator and 2–4 distinct independent reference implementations. References
must pass official tests and agree on the new output; the old submitted program
must reproducibly fail it. Generated tasks keep the parent source cluster and
cannot manufacture independent statistical units. Oracle review is an external
trust assumption, not something established by syntactic code diversity. Missing
Oracle is PENDING/CAPABILITY_UNSUPPORTED, never reward-bearing.

Real models can propose replacement research-control-v1 functions, branches and
loops. A train-public control trace difference is required before submission;
Controller then evaluates task and meta interventions independently with parent
model/instructions, opponent and episode ceilings fixed, including rollback.
Fixed-meta RSI can change task instructions, but its workflow stays fixed.
Direct and Self-Repair remain explicitly authored baselines.

Validation: three additional tests cover Oracle agreement/binding/answer rejection,
independent single-program proof verification/tampering, and model-proposed control
behavior with fixed parent adaptation. APPS subset: 14 tests passed. Full regression:
104 tests passed. All model/Judge/Oracle behavior tests use labeled protocol
fixtures. Live Oracle and statistical meta improvement have not been established.
