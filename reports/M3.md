# M3 — Executable invention algorithms

Added a bounded typed functional VM, bottom-up enumerative synthesis, executable
subtree recombination, type-preserving analogy substitution, grammar-constraint
relaxation and executable feature reframing. Candidates contain actual source,
interfaces, provenance, parent and evidence hashes. Behavioral duplicates and
non-improving training fits do not count as inventions. No oracle or private
evaluation feedback enters generation.

Active experiment synthesis searches multi-step primitive sequences to separate
executable hypotheses. The generated protocol is itself executable. A regression
case requires two steps: all single-step experiments agree, while the synthesized
sequence discriminates a memoryless and a stateful explanation.

Actually run: 52 tests pass (all earlier tests plus seven invention/execution/
privacy/resource tests). Local search is an explicit real program-synthesis
backend, not a model simulation. The new algorithm components are integrated
into the coevolution runtime in subsequent integration work; the legacy runtime
remains a separately labeled baseline. No LLM, training or scientific validation
is claimed by this stage.
