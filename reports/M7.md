# M7 — Integration, controls, restricted execution and delivery audit

System changes:

- CLI exposes both generic stateful mechanisms, real model/training controls,
  conformance, eleven separately sealed baseline/ablation runs and Replay.
- Pure research ASTs execute in a spawn worker for full stateful runs and Replay.
  Only bounded JSON crosses the pipe; no evaluator-private memory is forked.
  Worker audit policy denies file/network/process/ctypes operations, with CPU,
  wall, call and memory bounds. macOS uses a disclosed 20ms parent RSS monitor
  because it rejects RLIMIT_AS; this is not zero-overshoot kernel memory isolation.
- Generation-time prediction and conservative search allocations now enter the
  controller ledger before execution; model/training failure calls remain logged.
- Independent bounded identifiability certificates supplement world legality,
  nontriviality, discrimination and duplicates. Action budgets are negotiated.
  Restricted worlds cannot smuggle unregistered primitives; malformed worlds
  return INVALID, and insufficient identification returns PENDING.
- Model meta programs execute to rank actual candidates using train evidence;
  tests show a changed program reverses selection. Role training rewards use the
  appropriate independent Scientist quality / Challenger boundary metric.
- LoRA-only fixes the generator template, prompts and sampling seed, and compares
  before/after weight-derived programs with an additional independent control.
  RL retains exact sampled tokens and uses an unfiltered, explicit sampling
  configuration and dropout-free likelihood calculation.
- Replay verifies checkpoint role/base/data/checksums; external adapters require
  installed trusted plugins and real assets, never simulated benchmark scores.

Key files/functions: `runtime/sandbox.ResearchSandbox`,
`core/identification.identify_world`, `core/controller.run_rsi`,
`runtime/model_research.ModelResearchRuntime`, `experiments/suite.comparison_suite`,
`adapters/registry.external_adapter`, `scripts/demo.py` and the unified CLI.

Validation: final 79 behavioral/failure/regression tests pass; both stateful
adapters pass all 13 conformance checks. Both two-generation complete local runs
replay (211 / 136 episodes). Both domains also execute all eleven one-generation
method controls in separate sealed directories. Compile checks, wheel build,
isolated installation smoke and protected-file/hash review pass. Exact records
are in CODE_COMPLETE_REPORT and the committed evidence bundle.

Audit found and fixed missing generation prediction costs, overly broad
identifiability wording, malformed proposal exceptions, restricted-track primitive
validation, incomplete model failure logs, ineffective model-meta ranking and
incorrect use of Scientist quality as Challenger training reward. Outer Gate,
Archive, formal spec and all 24 locked choices are unchanged.

Limitations: real neural inference/training/checkpoint loading and GPU paths are
implemented but unverified here; no credentials, provisioned weights or optional
training libraries exist. No external benchmark run, hard GPU-time/FLOPs quota,
arbitrary Python sandbox, infinite-family proof or nondeterministic exact Replay
is claimed. Local reflection/hardness/random controls have explicit bounded
algorithm definitions and do not substitute for external strong baselines.
H1–H4 remain entirely unverified. See CODE_COMPLETE_REPORT for each scope boundary.
