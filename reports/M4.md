# M4 — Challenger generation and independent worlds

World search consumes frozen executable hypotheses, train evidence and certified
boundary witnesses. It searches nontrivial, distinguishing programs and emits
actual source rather than an asserted answer. Independent certification checks
types, resource bounds, two interpreter semantics, nontriviality, discriminating
sequences, behavioral duplicates and bounded identifiability. Insufficient
certification budget or missing competing models is PENDING, not rewarded.
Both compositional A and open bounded-program B tracks execute real programs.

Added independent stateful SCM and string-transducer environments. Their
adapters contain semantics, sessions, source partitioning, scoring and audit,
not fitting/invention. Generated worlds belong only to train. Holdout scoring
uses trajectories longer than the discovery budget with no true-state teacher
forcing. The generated source namespace excludes the public low-complexity
family without querying private dev/test answers.

Actually executed: 56 regression tests passed; both new adapters compiled and
independently certified newly searched B-track worlds. Four dedicated world
tests cover both tracks, duplicate/trivial/undiscriminating worlds, false author
answers, budget uncertainty and dependence on frozen hypotheses. These are
controlled integration environments, not CausalGame/KernelBench results.
