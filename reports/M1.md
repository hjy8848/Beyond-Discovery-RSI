# M1 — 通用 Domain Protocol 阶段记录

日期：2026-10-23。范围：Domain Protocol 1.1 与既有系统的增量接入；**不是 M2–M7 完成声明，也不是 H1–H4 的实验证据**。

## 审阅结论与复用

原 Controller 的代初父版、双边候选屏障、固定对手选代、四组合审核和冻结测试流程可复用。Gate 与 Archive 本阶段逐字节保持不变。Replay 保留实现哈希与确定性复算，增加协议协商及产物版本检查。锁定规范与 Decision Lock 均未更改，SHA-256 复核通过。

原来的领域假设分散在交互执行、预算计算、初始表示、世界提案和发明调度中。有限表达式算法被明确保留为 `FiniteResearchRuntime` 兼容基线；没有把它改名宣称通用发明，也没有把求解算法放进 Adapter。

## 系统行为变化

- Controller 使用 `DomainCapabilities` 与 `negotiate()`，不再读取有限输入全集、输入维度或整数表达式算子。预算来自 Adapter 的声明，使用相同的预留额度进行配对；拒绝超额、负数和能力漂移。外层 Gate 的接受规则与阈值没有变化。
- 通用 `Action`、不可变规范 JSON 载荷和结构化 `Observation` 支持有状态会话、顺序号与终止状态。会话必须显式关闭；非法动作在状态修改之前拒绝。
- `ResearchArtifact` 保存可执行源代码、语言、接口 schema、版本、来源与内容哈希。`research-workflow-v1` 实际执行多步原语调用，后续动作可以引用之前的观察。产出也是可执行的结果 artifact，独立评分器不会把它提供的结果当成标准答案。
- 候选与元策略生成接口接收公开领域描述和 train 证据，不接收 Adapter 对象或 dev/test 证据。独立评估仍执行 dev/test 任务，但这些证据不进入生成、训练或 Prompt。
- Archive 记录协商结果、能力哈希、运行时 ID、快照中的完整产物及资源分配。Replay 恢复产物并重执行同一有状态协议；能力或版本变化会拒绝。
- 新增真实的文档编辑状态机作为协议一致性参考环境，独立参考实现审核编辑轨迹与结果。它只有一个来源簇，不把重复协议任务假装为独立科研世界。
- 完整能力默认要求双轨世界创造。参考文档环境不支持该能力，只有显式的 `protocol-only` / `fixed` 模式才可运行；通用发明模式直接报 `CAPABILITY_UNSUPPORTED`，不会用人工程序填补算法。

## 实际运行记录

1. 改动前运行原有套件：23 项通过。
2. 新增验收测试先失败：缺少通用协议模块。实现后，最终运行 `PYTHONPATH=src python3 -m unittest discover -s tests -v`：**41 项通过**，含原有 23 项与新增 18 项，运行时间约 22 秒。
3. CLI `conformance` 分别在 causal、vector、document 上通过，每个实际执行 13 类检查，包括预算拒绝、会话隔离、证据/评分篡改拒绝与分区保密。额外测试确认永远返回 True 的审核器和不执行预算限制的 Adapter 会被一致性检查拒绝。
4. CLI 执行文档产物的一代固定协议流程：完成；真实记录 18 次实验动作、12 次结果评分、24 条工作流指令、54 次参考输出检查，模型 Token 与训练步数均为 0。
5. 上述 CLI 运行的 Replay：6 个 episode 重新执行一致，共核验 12 条链式记录。没有调用模型。
6. 原有两个有限领域的双边候选、固定对手、版本继承/回滚与 Replay 均在原回归测试中实际执行通过。
7. 复核锁定设计哈希、Decision Lock、`core/gate.py` 与 `core/archive.py`：与基线提交 `90a22f4` 的文件一致。
8. 离线构建 `beyond_discovery_rsi-0.2.0-py3-none-any.whl` 成功，没有安装联网依赖。

这些分数与固定程序输出仅用于工程校验，不用来选择实现方案或报告科学增益。原始审计目录含私有评测证据，继续只保存在本地，不随代码上传。

## 尚未解决与未验证路径

- M2 的有限空间证伪、搜索失败与资源不足的证书分类尚未实现；原有限基线的边界解释不能当成通用空间不可表达性的证明。
- M3/M4 的证据驱动产物发明、类比迁移、开放世界独立认证尚未实现。工作流样例是明确的人工协议测试，不是模型生成或科学发现。
- M5 的通用可执行元策略生成与归因、M6 的真实模型/工具/角色训练/checkpoint 全链路、M7 的完整消融与外部基准仍待对应阶段实施。
- 受限工作流目前是有界数据流程序，支持原语调用、公开观察引用与返回；不支持分支、循环、任意 Python、文件或网络。没有声称已具备任意代码的操作系统沙盒。
- 使用显式支持的 JSON Schema 子集，未知约束拒绝。不是完整 JSON Schema 标准实现。
- 精确重执行 Replay 仅支持确定性 Adapter；随机模型响应保留原记录，非确定性环境的审计回放仍未实现。历史实现版本的日志须使用其原始版本复算，不静默改写旧证据。
- 本阶段没有调用付费模型、进行 LoRA/RL 训练、装载真实 checkpoint 或运行 GPU/外部 benchmark；未报告这些路径的验证成功。

下一阶段为 M2：在本阶段协议上建立可独立验证的 `BoundaryCertificate`，解决“模型预测错误不等于表示空间被证伪”的问题。
