# M5 — Executable role-independent meta evolution

Meta policies are now executable typed programs over invention evidence, cost,
complexity, novelty and coverage. Program synthesis proposes policies with
different rankings, rather than treating source changes as improvements.

affect frozen-model selection and synthesized experiments/world proposals.

Fixed adaptation opportunities bind the parent task program, frozen opponent,
train inputs and budget. Independent paired gates measure valid-method yield,
separately from task scores. The controller records proposed source, source diff,
gate evidence and rollback. A meta-only acceptance can preserve the parent task
program; task improvement does not automatically establish meta improvement.

M4 world search and both role meta programs to the original controller barriers,
independent gates, compatibility audit and deterministic Replay. Challenger
credit requires independently certified family refutation, not a model error.
